# Bookmark Tab Manager

A beautiful, fast new-tab replacement for Chrome and Firefox — organize bookmarks into folders and spaces, with a customizable clock, weather, themes, and productivity tools built in.

- 🌐 [Chrome Web Store](https://chromewebstore.google.com/detail/liamjkjiaklgnjeemocgmlmlgbgomloj)
- 🦊 [Firefox Add-ons](https://addons.mozilla.org/en-GB/firefox/addon/bookmark-tab-manager-fx/)
- 🔒 [Privacy Policy](https://yashwanthramsomireddy.github.io/bookmark-tab-manager/privacy-policy.html)

## What it does

Bookmark Tab Manager replaces your browser's new tab page with an organized, visual home for your bookmarks:

- Unlimited spaces, folders, and bookmarks with drag-and-drop organization
- Import your existing Chrome or Firefox bookmarks in one click
- Live clock, weather widget, and dark/light themes
- Global search, tags, and a privacy mode for screen sharing
- Session tracker — see your recent browsing activity at a glance
- Broken link checker, import/export, and more

**Pro** unlocks visual customization (50+ gradient themes, video and Unsplash backgrounds, particles), productivity tools (AI-powered auto-categorize, heatmap, streak tracking, weekly reports), child lock with a PIN, ambient sounds, dual-timezone clocks, unlimited incognito access, and Markdown export.

## Availability

Works identically on **Chrome** and **Firefox** — one license key activates on both. Available worldwide; pricing shown in INR via Razorpay.

## Privacy

Your bookmarks, folders, and settings are stored locally in your browser and never leave your device. A small, clearly-scoped set of features (Pro license validation, the weather widget, AI Auto-Categorize) send only the minimum data needed to work — see the full [Privacy Policy](https://yashwanthramsomireddy.github.io/bookmark-tab-manager/privacy-policy.html) for exactly what's sent, when, and why.
