FAQ

Common questions

Is my data safe? Does Bookmark Tab Manager collect anything?
Zero data collection. Everything — your bookmarks, settings, themes — is stored locally in your browser using Chrome's built-in storage. Nothing is ever sent to any server. We have no servers.
Can I import my existing Chrome bookmarks?
Yes! Go to Chrome → Bookmarks → Export bookmarks (saves as HTML). Then in Bookmark Tab Manager click Import → upload that file. All your folders are imported automatically in seconds.
What happens if I uninstall? Do I lose my bookmarks?
We strongly recommend using the Backup feature (Settings → Full backup) before uninstalling. The backup JSON file contains all your bookmarks and settings and can be restored on any device.
How many devices can I use Bookmark Tab Manager Pro on?
Monthly & Yearly: Up to 5 device activations per license.
Lifetime: Unlimited devices — install on as many as you want.

If you reinstall the extension or get a new laptop and run out of activations, contact us at yashwanthramsomireddy@gmail.com and we'll reset your activations immediately.
If I uninstall and reinstall the extension, do I lose my Pro access?
No! Just enter your license key again after reinstalling — it will reactivate. Make sure to use the Backup feature before uninstalling to save all your bookmarks and settings too.
After purchase you receive a license key by email. Open Bookmark Tab Manager → click the 🔒 Free badge → enter your key → Pro unlocks instantly. Monthly/yearly licenses renew automatically. Lifetime is one-time forever.
Which browsers are supported on laptop / desktop?
Bookmark Tab Manager works on all Chromium-based desktop browsers:

✅ Google Chrome — Primary, fully supported
✅ Microsoft Edge — Works perfectly
✅ Brave Browser — Works perfectly
✅ Vivaldi — Works perfectly
✅ Opera — Works perfectly
❌ Firefox — Not supported (different extension system)
❌ Safari (Mac) — Not supported (Apple restriction)
Does Bookmark Tab Manager work on mobile phones?
Android:
✅ Kiwi Browser — Install free from Play Store. Supports Chrome extensions fully. Install Bookmark Tab Manager exactly like desktop Chrome.
❌ Chrome on Android — Google does not allow extensions on mobile Chrome.
❌ Samsung Internet — Does not support new tab extensions.

iPhone / iPad (iOS):
❌ Not supported — Apple does not allow browser extensions of this type on iOS Safari or any iOS browser.
Can I use Bookmark Tab Manager in incognito mode?
Bookmark Tab Manager cannot replace the new tab page in Incognito mode. This is a Chrome browser security restriction that applies to all new tab extensions — not just Bookmark Tab Manager. Chrome intentionally blocks new tab overrides in Incognito to protect your privacy.

Bookmark Tab Manager works fully in all regular (non-incognito) tabs. For private browsing needs, simply open a regular tab and use Bookmark Tab Manager as normal — your bookmarks and data are stored locally and are not tracked.
